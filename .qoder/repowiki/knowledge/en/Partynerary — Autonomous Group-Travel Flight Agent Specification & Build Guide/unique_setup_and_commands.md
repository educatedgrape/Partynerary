Phased build gates are run via `python -m unittest ...` and dedicated scripts such as `LIVE=1 python -m probe.probe smoke`, `LIVE=1 python probe/breadth.py --origin SIN --date <YYYYMMDD>`, `python tools/generate_dataset.py --findings FINDINGS.md --out data/cities.json`, and `python tools/build_vectors.py --dataset data/cities.json --out data/vectors.json`. A `grep -rn 'PLACES = \[' probe/ src/` check enforces the no-handwritten-capture-list rule.
